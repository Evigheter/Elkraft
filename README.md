# Schaktbredd Calc+

**Schaktbredd Calc+** är ett webbaserat verktyg för att beräkna schaktbredd vid förläggning av kablar och rör enligt praktiska regler inom elkraftsbranschen.

### 🔧 Funktioner
- Beräknar total schaktbredd automatiskt
- Stöd för både **kabel och rör**
- Specialregler för **OPTO**
- Fri placering (dra och släpp)
- Visuell illustration av schaktet
- Automatisk avrundning till närmaste 0,1 m
- Koppling till **Schakttabell (Ellevio A–A till Z–Z)**

### 📐 Beräkningsprincip
- 0,1 m sidoutrymme på varje sida
- Mellanrum:
  - Rör–rör → ½ största diameter
  - Kabel/rör → största diameter
  - OPTO–OPTO → 0 mm
  - OPTO–annat → 50 mm

### 🎯 Användning
Verktyget kan används för:
- Projektering
- Beredning
- Snabba kontroller i fält
- Granskning
